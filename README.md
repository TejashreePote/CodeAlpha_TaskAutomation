# CodeAlpha Task Automation

## Project Overview

This project is developed as part of the CodeAlpha Python Programming Internship.

The project demonstrates task automation using Python. It automatically finds all JPG image files from a source folder and moves them to a destination folder.

## Features

- Detects JPG files automatically
- Creates the destination folder if it does not exist
- Moves JPG files from the source folder
- Displays the names of moved files
- Uses Python file and folder handling

## Technologies Used

- Python
- os module
- shutil module
